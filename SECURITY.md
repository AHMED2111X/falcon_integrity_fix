# Security Policy — FALCON INTEGRITY FIX

## Supported Versions (الإصدارات المدعومة)

| Version | Supported |
| ------- | --------- |
| v3.27+  | ✅ Yes / نعم |
| v3.26   | ⚠️ Update recommended / يُنصح بالتحديث |
| < v3.26 | ❌ No / لا |

## Reporting a Vulnerability (الإبلاغ عن ثغرة أمنية)

**English:** Please report security vulnerabilities **privately** via Telegram [@falcon_kernel](https://t.me/falcon_kernel) or the support group [@falcon_support_root](https://t.me/falcon_support_root). Do NOT open a public GitHub issue for security vulnerabilities.

**العربية:** للإبلاغ عن أي ثغرة أمنية في الوحدة، استخدم تليجرام الخاص: @falcon_kernel أو مجموعة الدعم: @falcon_support_root. يُرجى **عدم فتح إعلان عام (Issue)** على GitHub للثغرات الأمنية.

- ⏱️ Expected response: within 48 hours / وقت الرد المتوقع: خلال 48 ساعة
- ✅ If accepted: fixed in the next release / إذا قُبلت: تُصلَّح في الإصدار التالي
- ❌ If declined: you will receive an explanation / إذا رُفضت: ستصلك التوضيحات
